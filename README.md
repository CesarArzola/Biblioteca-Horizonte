# 📚 Biblioteca Horizonte

Sitio web interactivo desarrollado a partir de un wireframe para el proyecto **Biblioteca Horizonte**. El proyecto consiste en el desarrollo *front-end* de una interfaz web funcional que combina HTML para la maqueta, CSS (Flexbox) para el diseño visual responsivo y JavaScript para la manipulación dinámica del DOM e interactividad del usuario.

---

## 🎯 Objetivo de Aprendizaje

Desarrollar una interfaz web funcional a partir de un wireframe entregado, aplicando:
- **HTML5** para la definición de la estructura y contenido semántico.
- **CSS3 y Flexbox** para la maquetación, distribución y organización visual.
- **JavaScript (ES6)** para incorporar interactividad y manipulación del DOM.

---

## 🚀 Funcionalidades

El sitio web incluye las siguientes características interactivas requeridas en la actividad:

1. **Inicio de Sesión:** Formulario funcional de autenticación simulada de usuario.
2. **Mensaje de Bienvenida:** Interacción dinámica que despliega un saludo personalizado al usuario tras iniciar sesión.
3. **Efecto al Pasar el Cursor (*Hover*):** Cambio dinamico e interactivo de contenido e imágenes al posar el puntero sobre los elementos de la interfaz.
4. **Contador de Libros Seleccionados:** Lógica en JavaScript que contabiliza y actualiza en tiempo real el número de libros agregados o seleccionados por el usuario.
